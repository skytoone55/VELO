1. Workflow global : parcours d'un dossier

Chaque dossier client suit un parcours en 5 phases. Voici les statuts et les actions qui font avancer le dossier.

PHASE 1 — CONTROLE Nouveau client → Controle valide Auto : le code NAF est verifie automatiquement a l'import PHASE 2 — FORMULAIRE Vous cliquez sur Envoyer formulaire Controle valide → Formulaire envoye → Formulaire valide Le client remplit le formulaire en ligne (6 etapes) PHASE 3 — PLANIFICATION Vous cliquez sur Planifier Formulaire valide → A livrer → Programmee Vous assignez un jour, un creneau et un livreur dans le planning PHASE 4 — LIVRAISON Le livreur clique sur Livraison Programmee → En livraison → Livree Le livreur complete le module de livraison (4 etapes terrain) PHASE 5 — CONTROLE QUALITE L'admin clique sur Valider Livree → CQ en cours → CQ valide Verification des 6 points post-livraison
ⓘ
Raccourci : si le client ne peut pas remplir le formulaire, le bouton Bypass permet de sauter directement a la Phase 3.

2. Action : Envoyer le formulaire

Conditions requises

  • Le client doit etre au statut Controle valide ou Formulaire envoye
  • La validation NAF doit etre OUI
  • Le client doit avoir une adresse email renseignee

Depuis la liste des clients

1
Cliquer sur les ⋯ (trois points) a droite de la ligne du client.
2
Cliquer sur Envoyer formulaire dans le menu deroulant.
Ce bouton n'apparait que si les conditions ci-dessus sont remplies.
3
Une fenetre de confirmation apparait :

Envoyer le code + formulaire

Un code de validation et le lien du formulaire seront envoyes a client@exemple.fr
Annuler Envoyer
4
Resultat : le client recoit 2 emails :
Email 1 : Son code de validation ENEMAT (a saisir a l'etape 1 du formulaire)
Email 2 : Le lien vers le formulaire en 6 etapes + instructions
Le statut passe automatiquement a Formulaire envoye.

Depuis la fiche client

Meme action, mais le bouton est directement visible en haut de la fiche :

← Envoyer formulaire Copier lien Livraison Mail livraison Mail planning
Les boutons visibles dependent du statut actuel du client.
✔
Copier lien permet de recuperer l'URL du formulaire pour l'envoyer manuellement (SMS, WhatsApp, etc.).

Le client confirme ou modifie l'adresse ou le velo sera livre. L'adresse est geocodee automatiquement pour determiner le depot le plus proche.

Quand un client n'a pas rempli son formulaire apres l'envoi initial.

1
Dans la liste clients, cliquer sur ⋯ → cliquer sur un des boutons d'action email disponibles, ou utiliser la selection multiple pour relancer en masse (voir section 12).
✓

5. Action : Bypass livraison

Pour creer directement une livraison sans passer par le formulaire (client injoignable, pas d'email, urgence, etc.).

1
Dans la liste clients, cliquer sur l'icone orange ⚡ (eclair) ou via le menu ⋯ → Passage direct en livraison.
2
Double confirmation obligatoire :

Passage direct en livraison

Vous allez bypasser le formulaire pour DUPONT SARL et le passer directement au statut "A livrer". Cette action est tracee.
Annuler Continuer

Confirmation finale

Etes-vous sur ? Le client DUPONT SARL (statut actuel : controle_valide) sera passe a "A livrer" sans formulaire.
Annuler Confirmer le bypass
✓
Resultat :
Le client passe directement a A livrer. Une livraison est creee. Le bypass est trace dans les logs.

7. Action : Envoyer les emails de planning

Trois niveaux d'envoi sont disponibles :

NiveauBoutonCe que ca fait
Un client Mail planning (sur la carte du client) Envoie l'email de confirmation de creneau a ce client uniquement
Un creneau Mail planning (N) (panneau droit) Envoie a tous les clients de ce creneau
Une journee Mail planning (N clients) (en-tete du jour) Envoie a tous les clients planifies ce jour-la
ⓘ
L'email contient : la date, le creneau, l'adresse du depot (si retrait), et des boutons Confirmer / Refuser que le client peut cliquer directement.
⚠
La reponse du client (confirme/refuse) est visible dans la liste des livraisons : ✓ Confirmee ✕ Refusee ⏳ En attente
