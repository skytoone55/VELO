1. Presentation de la plateforme

La plateforme Velo CRM est un outil de gestion commerciale concu pour le suivi des dossiers velos-cargos electriques. Elle couvre l'ensemble du cycle de vie d'un dossier client, de la validation du code ENEMAT jusqu'a la livraison et le controle qualite.

Deux entites, une seule plateforme

PPE EnergieEcovolt
Zone geographiqueFrance metropolitaineDOM-TOM (971, 972, 973, 974)
Module livraisonInterne (dans la plateforme)Externe (application partenaire)
CouleurVertJaune / vert
Emailvelo-cargo@patrimoine-energie.fradmin@eco-volt.fr
ⓘ
Les deux entites partagent le meme code et la meme interface. Seules les donnees, les emails et le module de livraison different.

Ce que permet la plateforme

  • Suivi complet des dossiers clients (statuts, documents, contact)
  • Envoi automatise de formulaires et relances par email
  • Planification et suivi des livraisons
  • Geolocalisation des clients et assignation aux depots
  • Controle qualite post-livraison
  • Synchronisation avec Monday.com (base historique)
  • Gestion multi-roles (super admin, admin, agent, livreur)

La fiche client regroupe toutes les informations d'un dossier sur une seule page.

Identification

  • Raison sociale, SIRET, reference dossier, numero de devis
  • Format juridique, code APE/NAF, nombre de salaries

Contact

  • Nom et prenom du contact, fonction
  • Email principal, email beneficiaire, telephone

Adresses

  • Adresse siege : adresse de la societe

7. Le formulaire client (parcours public)

Le formulaire est un parcours en 6 etapes que le client remplit lui-meme apres avoir recu un email d'invitation.

Comment envoyer le formulaire

Dans la liste des clients, trouver le client concerne.
Cliquer sur Envoyer formulaire dans les actions.
Le client recoit 2 emails :
  • Un email avec son code de validation ENEMAT
  • Un email avec le lien vers le formulaire
Le statut passe automatiquement a formulaire_envoye.

Les 6 etapes du formulaire (cote client)

Etape 1 — Code ENEMAT

Le client saisit le code de validation ENEMAT recu par email. Ce code prouve qu'il a bien ete contacte par votre equipe.

Etape 2 — Informations societe

Verification et completion des informations de l'entreprise : raison sociale, SIRET, contact, telephone.

Etape 3 — Adresse de livraison

Le client confirme ou modifie son adresse de livraison. L'adresse est geocodee automatiquement.

Etape 4 — Preferences de livraison

Le client choisit :

  • Ses jours de disponibilite (lundi a samedi)
  • Ses creneaux preferes (matin, apres-midi)
  • Un contact supplementaire si besoin
  • Des commentaires libres

Etape 5 — FNUCI

Information sur le numero FNUCI (identification du velo) qui sera attribue a la livraison.

Etape 6 — Confirmation

Recapitulatif de toutes les informations saisies. Le client valide et le statut passe a formulaire_complete.

✔
Un email de confirmation recapitulatif est automatiquement envoye au client apres validation.

Que se passe-t-il si le client ne remplit pas le formulaire ?

Vous pouvez :

  • Relancer : cliquer sur Relancer → un nouvel email est envoye
  • Reinitialiser : si le formulaire est bloque, cliquer sur Reset formulaire pour permettre au client de recommencer
  • Bypass : si le client ne peut pas remplir en ligne, cliquer sur Bypass livraison pour creer directement la livraison manuellement

Les filtres de la carte

La carte dispose de filtres avances :

  • Agence : filtrer par agence commerciale
  • Depot : selectionner un ou plusieurs depots specifiques
  • Statut : filtrer par etape du processus
  • NAF : validation NAF (valide/bloque/en attente)
  • Zone : dans la zone / hors zone / non assigne
  • Type de depot : retrait / logistique
  • Rayon : curseur pour ajuster le rayon visible

Reassigner les clients aux depots

Le bouton Reassigner les clients recalcule l'assignation de tous les clients aux depots les plus proches.

Cliquer sur Reassigner les clients.
Le systeme parcourt tous les clients sans depot ou avec au moins un depot manquant.
Pour les clients sans coordonnees GPS, le systeme geocode automatiquement par code postal (fallback).
Chaque client est assigne au depot le plus proche selon la distance a vol d'oiseau.
Un recapitulatif s'affiche :
  • X reassigne(s) : clients dont le depot a change
  • X geocode(s) par CP : clients sans GPS geocodes par code postal
  • X hors zone : clients trop eloignes de tout depot
  • X sans GPS ni CP : clients impossibles a localiser
⚠
Hors zone ne signifie pas "sans depot". Un client hors zone est quand meme assigne au depot le plus proche, mais il est marque comme etant au-dela du rayon de couverture normal.

Cliquer sur un client

Un clic sur un point client ouvre une info-bulle avec les details du dossier et un lien direct vers la fiche client.

12. Le controle qualite (CQ)

Super Admin Admin

A quoi ca sert

Apres chaque livraison, un controle qualite est effectue pour verifier que le dossier est complet et conforme. Le CQ verifie 6 points obligatoires.

Les 6 points de controle

#PointCe qu'on verifie
1Piece d'identitePhoto de la CI/passeport du beneficiaire presente et lisible
2Photo ENEMATPhoto de la plaque ENEMAT du velo presente et lisible
3Signature installateurLe livreur a bien signe le bon
4Signature clientLe client a bien signe le bon
5FNUCILe numero FNUCI est renseigne et valide
6VeloLes informations du velo sont correctes

Processus de controle

Ouvrir la page Controle Qualite depuis le menu.
Verrouiller le dossier : cliquer sur Prendre en charge pour que personne d'autre ne le traite en meme temps.
Verifier chaque point : cocher les 6 cases une par une apres verification.
Si un point est non conforme, ajouter un commentaire explicatif.
Cliquer sur Valider le controle quand les 6 points sont verifies.
Le dossier passe au statut controle_valide.

Filtres CQ

FiltreDescription
RecherchePar raison sociale, SIRET
Statut livraisonLivree, a verifier
DatePlage de dates de livraison
AgentPar livreur qui a effectue la livraison
⚠
Ne pas oublier de deverrouiller un dossier si vous ne pouvez pas le terminer. Cliquer sur Liberer pour permettre a un collegue de le reprendre.

16. Workflow complet : du client a la livraison

Voici le parcours complet d'un dossier client, de bout en bout :

Phase 1 — Controle initial

Nouveau client → Controle valide

Le client arrive en base (import Monday ou creation manuelle). Son code NAF est verifie automatiquement.

Phase 2 — Formulaire

Controle valide → Formulaire envoye → Formulaire valide
L'admin/agent envoie le formulaire au client (Envoyer formulaire).
Le client recoit 2 emails (code + lien) et remplit les 6 etapes.
A la validation, le statut passe a formulaire_valide et une livraison est creee automatiquement.

Phase 3 — Planification

Formulaire valide → A livrer → Programmee
La livraison apparait dans le Planning comme "a planifier".
L'admin/agent assigne un jour, un creneau et un livreur.
Un email de confirmation de creneau est envoye au client.
Le client peut confirmer ou refuser le creneau via un lien dans l'email.

Phase 4 — Livraison

Programmee → En livraison → Livree
Le livreur voit la livraison dans sa vue terrain.
Il se rend sur place, ouvre le module de livraison.
Il complete les 6 etapes (CI, photo, FNUCI, signatures).
La livraison passe au statut livree.

Phase 5 — Controle qualite

Livree → Controle CQ → CQ valide
Le dossier apparait dans la page Controle Qualite.
Un admin verrouille le dossier et verifie les 6 points.
Si tout est conforme : validation. Si non : retour pour complement.
✔
Raccourci : pour les clients qui ne peuvent pas remplir le formulaire en ligne, utilisez le Bypass livraison pour passer directement a la phase 3.

18. Questions frequentes (FAQ)

Un client n'apparait pas dans ma liste

✔
Si vous etes agent secteur : verifiez que le client est bien assigne a l'un de vos depots. Allez sur la Carte et utilisez Reassigner les clients si necessaire.

Si vous etes admin : verifiez le filtre territoire. Un admin regional ne voit que les clients de son departement.

Le client dit ne pas avoir recu l'email

✔
  • Verifier l'adresse email dans la fiche client (fautes de frappe frequentes)
  • Demander au client de verifier ses spams / courrier indesirable
  • Utiliser Renvoyer le code ou Relancer pour renvoyer
  • En dernier recours : Bypass livraison pour passer outre

Comment changer le depot d'un client ?

✔
Le depot est assigne automatiquement par proximite geographique. Pour forcer un changement, modifiez l'adresse de livraison du client et relancez Reassigner les clients depuis la carte.

Un client est marque "hors zone"

✔
Cela signifie que le client est au-dela du rayon de couverture de tous les depots. Il reste quand meme assigne au depot le plus proche. Vous pouvez :
  • Augmenter le rayon de couverture du depot le plus proche
  • Creer un nouveau depot plus proche du client
  • Laisser en l'etat (la livraison peut quand meme etre effectuee)

Comment supprimer un document ?

✔
Ouvrir la fiche client, section Documents. Cliquer sur l'icone corbeille rouge a cote du document. Confirmer dans la fenetre de double validation. Attention : cette action est irreversible.
